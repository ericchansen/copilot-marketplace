# Source entry points and scope

These are discovery links, not a snapshot of the user's league. Open the
current relevant article/page and record its actual URL and observation time.
If an article redirects, hides content or cannot be retrieved, do not invent
its contents. Search summaries are leads, not authoritative evidence.

| Source | Use and boundary |
| --- | --- |
| [Yahoo Fantasy](https://sports.yahoo.com/fantasy/) | Discover the signed-in user's requested team/group through supported access; public home page does not prove ownership |
| [Yahoo Fantasy Football Help](https://help.yahoo.com/kb/fantasy-football) | Discover current sport-specific help; may need supported rendered access |
| [Yahoo default football settings](https://help.yahoo.com/kb/SLN6489.html) | Explains defaults and private-league customization; never import defaults as observed league rules |
| [Yahoo scoring overview](https://help.yahoo.com/kb/fantasy-football/standard-leagues-sln6868.html) | Scoring formats, live/official stats and corrections; verify applicable sport/window and resolve conflicting guidance before conclusions |
| [Yahoo Pro Football Pick'em scoring](https://help.yahoo.com/kb/SLN6624.html) | Scoring overview; inspect current expanded content and actual group rules |
| [Yahoo confidence points](https://help.yahoo.com/kb/SLN6640.html) | Confidence weighting, uniqueness and playoff differences; read actual allowed values |
| [Yahoo Pick'em tiebreakers](https://help.yahoo.com/kb/SLN6629.html) | Tiebreak criteria; separately inspect actual field deadlines, not inferred game times |
| [Yahoo developer entry point](https://sports.yahoo.com/developer/) | Starting point for current supported API documentation/terms; not evidence of a Pick'em or autonomous-agent API |
| [NFL injuries](https://www.nfl.com/injuries/) | Official football status discovery; follow the specific current report/team source, not just this index |
| [NFL schedule](https://www.nfl.com/schedules/) | Official football event discovery; does not establish fantasy locks |
| [NBA official portal](https://official.nba.com/) | Discover the requested season's injury reports; direct retrieval may be restricted, so report unavailable content rather than infer statuses |
| [MLB](https://www.mlb.com/) / [NHL](https://www.nhl.com/) | Discover official sport/team schedules and status sources; no assumed common eligibility or scoring |
| [Agent Skills specification](https://agentskills.io/specification) | Packaging: directory-matching lowercase hyphenated name (1-64 characters, no consecutive hyphens), description 1-1024 characters and progressive disclosure |

For current projections/markets, select credible providers that expose the
needed sport, scoring, event, handicap and update time. Cite the exact report
or market, not a search page. Read market-contract settlement/liquidity
information before interpreting prices. This plugin ships no price feed,
forecasts or historical accuracy claims.

Actual league pages are the primary source for settings, identity, roster,
deadlines, budgets, saved picks and outcomes. Conflicting public help cannot
silently override that evidence; clarify unresolved restrictions before
action. Do not send private league data to a public search engine.
